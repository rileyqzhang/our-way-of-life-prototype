要將原本 Weebly 雜亂的條列頁轉變為兼具溫度與學術重量的 **「Story Cards」原型**，並順暢過渡至 WordPress，你可以分兩步執行：先用這套乾淨、具備現代人文質感的 **Vibe Code (HTML + CSS)** 快速預覽效果；接著按照 WordPress 的架構將資料結構化。 --- ### 1. Prototype Vibe Code (單一檔案可直接瀏覽) 將以下程式碼儲存為 `index.html` 即可在瀏覽器開啟。視覺採用文檔式暖灰底色、高對比襯線引言、懸浮動態回饋，以及醒目的代號標記： ```html Our Participants | Story Archive

Weebly 轉移到 WordPress 的執行路徑 不用手動搬移幾十個 10 頁的故事，建議採取**模組化自訂文章型別（CPT）**： **架構與資料分離** * 安裝免費外掛 **Pods** 或 **ACF (Advanced Custom Fields)**。 * 建立一個名為 `Participants` 的 Custom Post Type (CPT)。 * 設定專屬欄位： * **Participant ID** (例如: `BMNJ`, `MGNJ`) * **Featured Pull Quote** (單句金句) * **Artistic Portrait** (特色圖片/插畫) * **Origins / Location** (例如: `Manhattan -> NJ`) * **Full Narrative** (WordPress 預設編輯器放完整的 10 頁故事與檔案) **視覺與列表渲染 (No-Code / Low-Code 做法)** * **Block Theme (全站編輯 / FSE)**：使用 WordPress 內建的 **Query Loop Block**，將版面設為 Grid，直接在編輯器內拖入 Post Featured Image、自訂欄位與引言。 * **頁面編輯器 (Elementor / Bricks)**：使用 Loop Builder，把上面 prototype 的結構套入單一卡片樣板，系統會自動將所有受訪者資料撈出並排版。 **資料搬運 (Migration)** * 由於 Weebly 的結構多為封閉式靜態頁面，最好的方式是將現有 Weebly 內容在試算表（Google Sheets / CSV）中整理好各欄位（ID、Quote、內容、圖片連結）。 * 在 WordPress 安裝 **WP All Import** 外掛，一鍵將 CSV 直接灌入剛建立的 `Participants` 自訂文章型別中。 你打算使用 WordPress 原生的區塊編輯器（Gutenberg），還是 Elementor 等頁面構建工具來架設？
